# Product IA

A skill that encodes a practical operating system for **Product Information Architecture** — focused on digital products and SaaS applications.

It helps design, audit, and restructure how products are organized so they make sense to users and scale cleanly over time.

## What this skill covers

- Ontology (core entities and relationships)
- Taxonomy and hierarchy design
- Controlled vocabulary and labeling
- Navigation systems (global, local, contextual)
- Tenant / Workspace / Project structure
- Role-based and permission-aware IA
- Findability and wayfinding

## Core Philosophy

Information architecture always exists. The only choice is whether it is intentional or accidental.

Key axioms:
- Consistency beats cleverness
- Organize by how users think, not by internal structure
- Language is structure
- Structure must scale without becoming a maze
- Controlled vocabulary is non-negotiable
